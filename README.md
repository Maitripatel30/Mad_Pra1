# MAD Practical-1 – Kotlin Programming Concepts

This repository contains the implementation of **Practical-1** for the **Mobile Application Development (MAD)** subject. It demonstrates fundamental Kotlin programming concepts, including variables, type conversion, input/output, control flow, functions, recursion, arrays, ArrayList, classes, constructors, operator overloading, and matrix operations.

## 📌 Practical Information

* **Subject:** Mobile Application Development (MAD)
* **Practical:** Practical-1
* **Language:** Kotlin
* **IDE:** Android Studio / IntelliJ IDEA
* **Repository:** [MAD_Pra1](https://github.com/Maitripatel30/Mad_Pra1)

---

## 📚 Practical Contents

### 1.1 Store & Display Values in Different Variables

Demonstrates the declaration and display of variables using different Kotlin data types:

* Integer (`Int`)
* Double (`Double`)
* Float (`Float`)
* Long (`Long`)
* Short (`Short`)
* Byte (`Byte`)
* Character (`Char`)
* Boolean (`Boolean`)
* String (`String`)

---

### 1.2 Type Conversion

Demonstrates type conversion between different data types:

* Integer → Double
* String → Integer
* String → Double

Kotlin functions such as `toDouble()`, `toInt()`, and `toFloat()` are used for conversion.

---

### 1.3 Scan Student's Information and Display All the Data

Takes student information as input from the user and displays the entered details.

Example information:

* Student Name
* Enrollment Number
* Branch
* Semester
* Division
* Other student details

This practical demonstrates Kotlin's `readLine()` input functionality.

---

### 1.4 Check Odd or Even Numbers

Determines whether a given number is **Odd** or **Even** using a conditional expression directly within the `println()` statement.

Example:

```text
Enter number: 10
10 is Even
```

---

### 1.5 Display Month Name

Uses the Kotlin `when` expression to display the month name based on the number entered by the user.

Example:

```text
Enter month number: 8
Month: August
```

This demonstrates the use of `when` as a powerful alternative to multiple `if-else` conditions.

---

### 1.6 User-Defined Function

Creates a user-defined function to perform basic arithmetic operations on two numbers:

* Addition
* Subtraction
* Multiplication
* Division

This practical demonstrates how functions are declared and called in Kotlin.

---

### 1.7 Factorial Calculation with Recursion

Calculates the factorial of a number using a **recursive function**.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1
5! = 120
```

This practical demonstrates the concept of **recursion**, where a function calls itself until a base condition is reached.

---

### 1.8 Working with Arrays

Demonstrates different Kotlin array operations and looping techniques.

Topics covered:

* `Arrays.deepToString()`
* `contentDeepToString()`
* `IntArray.joinToString()`
* Array traversal
* Range (`..`)
* `downTo`
* `until`
* Array manipulation
* Sorting without built-in functions
* Sorting using built-in functions

Both manual sorting and Kotlin's built-in sorting functions are demonstrated.

---

### 1.9 Find Maximum Number from ArrayList

Creates an `ArrayList` of integers and finds the maximum value from the list.

This practical demonstrates:

* `ArrayList`
* Looping through collections
* Comparing values
* Finding the maximum element

---

### 1.10 Class and Constructor Creation

Demonstrates the creation of classes and constructors using a **Car** class.

The `Car` class contains properties such as:

* Type
* Model
* Price
* Owner
* Miles Driven

Functions are implemented to:

* Get car information
* Display car information
* Calculate/display original car price
* Calculate/display current car price

This practical demonstrates Kotlin's **Object-Oriented Programming concepts**.

---

### 1.11 Operator Overloading and Matrix Operations

Demonstrates **operator overloading** using a `Matrix` class.

The following matrix operations are implemented:

* Matrix Addition (`+`)
* Matrix Subtraction (`-`)
* Matrix Multiplication (`*`)

The `toString()` function is also overloaded to provide customized matrix output.

This practical demonstrates how Kotlin allows operators to be redefined for user-defined classes.
